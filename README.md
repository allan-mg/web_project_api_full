# TripleTen web_project_api_full

Proyecto full stack desarrollado como parte del bootcamp de Desarrollo Web de TripleTen.

La aplicación permite a los usuarios registrarse, iniciar sesión y utilizar una interfaz protegida mediante autenticación. Los usuarios pueden editar su perfil y avatar, crear y eliminar tarjetas, así como dar o quitar "Me gusta" a las tarjetas.

El proyecto integra un frontend desarrollado con React y un backend construido con Node.js, Express y MongoDB.

## Funcionalidad

- Registro de nuevos usuarios.
- Inicio de sesión mediante JWT.
- Autorización de rutas protegidas.
- Edición del perfil del usuario.
- Actualización del avatar.
- Creación de tarjetas.
- Eliminación de tarjetas propias.
- Dar y quitar "Me gusta" a las tarjetas.
- Validación de datos del usuario y de las tarjetas.
- Manejo centralizado de errores.
- Registro de solicitudes y errores.
- Recuperación automática del servidor mediante PM2.
- Comunicación segura mediante HTTPS.
